# Harkinz Portfolio

Open `index.html` in your browser or run it with VS Code Live Server.

## Add your photo

Find the `YOUR IMAGE HERE` section in `index.html` and replace the placeholder with:

```html
<img src="your-photo.jpg"
     class="h-full w-full object-cover"
     alt="Harkinz">
```

Put `your-photo.jpg` in the same folder as `index.html`.

## Customize

- Replace `hello@example.com`
- Replace GitHub / LinkedIn `#` links
- Edit project names and descriptions
- Change the HZ logo text if you have your actual logo
- Add your real project screenshots
